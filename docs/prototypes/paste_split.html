  휴대폰으로 책 문제 글자 가져오기
  
    
    
  • 아이폰: 카메라를 문제에 대면 오른쪽 아래 텍스트 인식 아이콘 → 문제 부분 선택 → 복사. (사진 앱에서 찍은 사진을 길게 눌러도 됩니다)
    • 
    
  • 안드로이드: 카메라 또는 Google 렌즈 → 텍스트 → 문제 부분 선택 → 복사.
    • 
    
  • PC로 옮기기: 카카오톡 나와의 채팅에 붙여 넣고 PC 카카오톡에서 복사 → 이 페이지에 붙여넣기.
    • 
    
  • ①②③ 같은 동그라미 숫자가 1) 2) 또는 (1) (2)로 읽혀도 자동 분리됩니다. 줄이 중간에 끊겨도 선지 안의 줄바꿈은 한 칸 띄어쓰기로 합칩니다.
    • 
  






  이 페이지가 하지 않는 것
  
    
    
  • 정답 번호는 자동으로 고르지 않습니다(책 정답표를 보고 직접 선택).
    • 
    
  • 시험 회차·연도를 추측하지 않습니다. 기준일은 오늘 날짜가 기본값이며 직접 바꿀 수 있습니다.
    • 
    
  • 앱으로 바로 보내지 않습니다. 복사한 JSON은 앱 입력 화면 개선(영주 님 작업)의 시험 자료입니다.
    • 
  






  본 기출문제의 저작권은 한국산업인력공단(Q-Net)에 있으며, 출처를 밝히고 사용하였습니다. 입력 편의를 위해 일부 재가공됨.
